# Python Learning Journey

Welcome to my Python Learning Journey repository!

This repository documents my hands-on learning experience in Python programming through a series of practical exercises completed as part of the SmartBizCrux Python Study Group.

Each lesson builds upon the previous one, progressing from fundamental Python concepts to programming logic, loops, functions, error handling, and practical problem-solving using real-world scenarios.

The primary goal of this repository is to strengthen my Python programming skills while building a well-organised portfolio that demonstrates my learning progress, practical understanding, and ability to apply Python to problems across areas such as business, healthcare, research, data, and automation.

---

## About This Repository

This repository contains a collection of Jupyter Notebooks organised into lesson folders. Each notebook focuses on a specific Python concept and includes practical exercises designed to reinforce learning.

The learning journey has progressively covered:

* Python fundamentals
* Variables and data types
* User input
* Arithmetic, comparison, logical, and assignment operators
* String manipulation and formatting
* Python data structures
* Conditional statements
* `for` loops
* `while` loops
* Nested loops
* Functions
* Error handling and debugging
* Exception handling
* Practical programming and industry-based exercises

Rather than learning Python syntax in isolation, many of the exercises are designed around realistic scenarios from healthcare, banking, e-commerce, education, payroll, inventory management, and customer service.

# How to Run the Notebooks

### 1. Clone this repository

```bash
git clone https://github.com/Promise-Steve/python-learning-journey.git
```

### 2. Navigate into the project folder

```bash
cd python-learning-journey
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 4. Open a lesson

Navigate to any lesson folder and open the relevant `.ipynb` notebook.

Run the cells sequentially to reproduce the exercises and outputs.
