# Python Learning Journey

Welcome to my **Python Learning Journey** repository!

This repository documents my hands-on learning experience in Python programming through a series of practical exercises completed as part of the **SmartBizCrux Python Study Group**. Each lesson builds upon the previous one, covering fundamental Python concepts and demonstrating their application through real-world examples.

The primary goal of this repository is to strengthen my Python programming skills while creating a well-organised portfolio that showcases my progress and practical understanding of core programming concepts.

---

## About This Repository

This repository contains a collection of Jupyter Notebooks organised into lesson folders. Every notebook focuses on a specific Python concept and includes practical exercises designed to reinforce learning.

Topics covered include:

- Python fundamentals
- Variables and data types
- User input
- Arithmetic operators
- Comparison operators
- Logical operators
- Assignment operators
- String manipulation
- String formatting
- String methods
- String indexing
- String slicing
- Practical programming exercises

# How to Run the Notebooks

1. Clone this repository:

```bash
git clone https://github.com/Promise-Steve/python-learning-journey.git
```

2. Navigate into the project folder:

```bash
cd python-learning-journey
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open any notebook from the lesson folders and run the cells sequentially.
